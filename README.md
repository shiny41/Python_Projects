* Voice Assistant

A Python-based voice assistant that recognizes voice commands and performs useful tasks through speech.

* Features

- Voice command recognition
- Text-to-speech responses
- Current time and date
- Google search
- Weather information
- Email sending
- Reminders
- Basic Python and AI knowledge responses
- Custom voice commands
- Error handling for speech recognition

* Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- Requests
- SMTP
- OpenWeatherMap API
- PyAudioWPatch

* How to Run

1. Install Python.
2. Install the required Python packages.
3. Open the project in VS Code.
4. Run `assistant.py`.
5. Allow microphone access when requested.
6. Speak a supported command.

* Example Commands

- "Hello"
- "What is the time?"
- "What is the date?"
- "Search Python programming"
- "What is Python?"
- "What is artificial intelligence?"
- "Weather"
- "Send email"
